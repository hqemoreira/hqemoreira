# 60-second hiring proof (locked narrative)

**Posture:** Personal reskilling · hiring conversations only · non-commercial · not a product for sale.

## Lead with GRYPS

I built a live research prototype that takes a Nordic / Arctic site profile and returns a **Resilience Signature** — score, grade, top risk, and ranked connectivity options — from a deterministic Model v0.4 engine.

**Open and try:** https://gryps.vercel.app/#advisor

1. Set latitude / longitude and an operational profile (providers, autonomy, criticality).
2. Generate a Signature (~1 minute).
3. Read score + grade + risks + ranked backups; optional AI prose never changes the score.
4. Methodology, assumptions, and limitations are documented on the project site.

**What it proves:** end-to-end ship of a domain scoring engine (Next.js, Neon, MapLibre, optional Mistral) for OT / satellite connectivity literacy.

**What it is not:** customer deployments, SLAs, live RF monitoring, procurement advice, or a SaaS.

## System vs stamps

- **The system (lead):** assess site → score (Model v0.4) → rank options → document Resilience Signature. Logic stays; stack is interchangeable.
- **Stamps (secondary):** SAP · Power BI · CRM · BW — real commercial-ops tools from prior roles; career evidence, not the hiring headline.
- **Never lead with:** model logos, “I use Cursor/Claude,” or a tool wall without the closed loop.
- **Walkthrough:** https://gryps.vercel.app/#advisor — no account / no email for the initial Signature.
